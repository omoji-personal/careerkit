## Refuted - recorded so they are not re-litigated

- **The "60-character lookbehind" defect did not exist in this engine.** It was
  diagnosed from a retired per-instance copy of score.py that nothing imports.
  The live engine replaced that window with sentence-clause analysis on 8/10.
  The lesson is operational: verify which code actually runs before diagnosing.
- **A posting surfacing despite twelve mentions of an excluded product was not
  a bug.** The mentions are comma-separated list items and the rail yields on
  lists deliberately, with the rationale recorded in score.py: a false block
  costs more than a surfaced role the user can judge. The heading gap (#2) was
  the real defect adjacent to it.
