# /outreach — the human channel
Draft referral asks, recruiter registrations, hiring-manager notes,
thank-yous, and nudges in the USER'S voice (style.md). Rules that make them
land: no invented deadlines or fake urgency; one specific answerable ask per
message; never re-touch a thread without genuinely new information; thank-yous
short and specific, no relitigating the interview.
The user supplies recipients (no contact scraping). autonomy: outreach
governs sending - default DRAFT-ONLY; the user sends from their own account.
Log sent messages + dates in tracker.md so timing rules hold.
