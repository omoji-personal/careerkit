# /evaluate — one role, honestly
Fetch the live posting. Score it. Then go past the score: required-vs-held
gap list (name each gap plainly), comp band vs floors, location reality,
employer signals (AI-policy clauses, clearance, travel, quota), and a
recommendation: APPLY / STRETCH-APPLY / SKIP with one-paragraph reasoning in
plain language. Log to tracker.md. Never soften a real disqualifier; the
user's time is the scarce resource.
